# The Clicking of Isaac

Прозрачный десктоп-виджет в стиле **Bongo Cat** с Айзеком на **Godot 4.7**.

## Возможности

- **Глобальный подсчёт кликов** — реагирует на нажатия мыши и клавиатуры в любых окнах Windows (встроенный лёгкий помощник распаковывается автоматически, поэтому для запуска нужен только один `.exe`).
- **Анимация лайка** — на каждый клик или нажатие клавиши Айзек показывает лайк с плавным подпрыгиванием.
- **Режим танца Specialist** — пункты **«Танцевать»** и **«Музыка танца»** в контекстном меню запускают 449-кадровый танец при 60 FPS под чиптюн-трек.
- **Оформление в стиле The Binding of Isaac** — счётчик на пергаментном свитке, кнопка меню в виде приколотой записки, шрифт `Upheaval Pro` (с поддержкой кириллицы).
- **Удобный оверлей** — режим «Поверх всех окон», перетаскивание мышью за любую область, масштаб (`0.75x`, `1x`, `1.25x`), звук лайка и автосохранение счётчика и позиции.

## Скачивание

Готовый однофайловый билд для Windows (x64) доступен в разделе [**Releases**](https://github.com/eskovirch/the-clicking-of-isaac/releases): скачайте `the clicking of isaac.exe` и запустите.

## Запуск из исходников

1. Откройте `project.godot` в **Godot 4.7+**.
2. При запуске из редактора отключите *Embed Game on Next Play* в панели **Game**, чтобы окно отображалось поверх всех окон с прозрачным фоном.
3. При экспорте под Windows включите **Embed PCK** для сборки в один `.exe`.
